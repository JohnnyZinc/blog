## 关于这个博客

这个站点是从我的 Obsidian 笔记库自动发布的：笔记库里有一个 `博客` 文件夹，里面写了什么，这里就有什么。
笔记库本身是私有的，只把 `博客` 这一个文件夹的内容（加上引用到的图片）同步到公开的博客仓库，
其余笔记不会出现在这里。

- 写笔记：Obsidian（Git 插件自动 commit / push 到私有库）
- 发布：GitHub Actions 用 `sparse-checkout` 只拉取 `博客` 文件夹 → 转换 Markdown → Hugo 构建 → GitHub Pages
- 主题：[LoveIt](https://github.com/dillonzq/LoveIt)
